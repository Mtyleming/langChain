# LangChain 学习笔记

这是一套从基础到进阶的 LangChain / Agent 学习示例代码，按课次编号，方便对照学习。

## 环境准备

1. 建议使用 Python 3.10+
2. 安装依赖后，在项目根目录运行对应课次文件即可：

```bash
python lesson_1_model.py
```
